# 문제 해결 가이드 (Troubleshooting)

언어 전환 시 발생할 수 있는 주요 상황별 원인 및 해결 방법입니다.

---

## 1. 배치 파일(.bat) 실행 시 관리자 권한 관련

### 특징 (v1.1.0부터 자동 승격 적용)
- 본 앱에서 생성되는 배치 파일은 **자동 관리자 권한 승격(UAC Self-Elevation)** 로직이 내장되어 있어, 파일을 일반 더블클릭하기만 해도 시스템 UAC 승인 팝업이 자동으로 호출됩니다.
- 팝업이 나타나면 **[예]**를 클릭하시면 권한 오류 없이 즉시 언어 전환이 완료됩니다.

### UAC 팝업이 뜨지 않거나 권한 획득에 실패하는 경우
1. 윈도우 보안 정책이나 사용자 계정 설정에 따라 자동 호출이 차단된 경우, 다운로드한 `.bat` 파일을 마우스 오른쪽 버튼으로 클릭합니다.
2. 메뉴에서 **[관리자 권한으로 실행]**을 수동으로 선택해 주세요.
3. "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?" 창이 뜨면 **[예]**를 누릅니다.

## 2. 콘솔 창이나 메모장에서 한글이 깨져 보이는 경우

### 해결 원리 및 상태
- 본 앱은 스크립트 파일 다운로드 시 **Windows CRLF (`\r\n`)** 개행 및 **UTF-8 with BOM (`0xEF, 0xBB, 0xBF`)** 형식을 강제로 주입하여 저장합니다.
- 배치 파일 첫머리에 `chcp 65001 >nul`이 포함되어 있어 윈도우 기본 CP949 콘솔에서도 한글 및 UTF-8 문자가 깨지지 않고 선명하게 출력됩니다.
- 만약 타 에디터에서 강제로 ANSI/EUC-KR로 재저장한 경우 한글이 깨질 수 있으므로, 웹에서 다시 다운로드하여 그대로 실행하시길 권장합니다.

## 3. "파일을 찾을 수 없습니다" 오류가 발생하는 경우

### 원인
- 설치된 포토샵 버전 연도와 웹에서 선택한 버전이 일치하지 않는 경우
- 영문 버전 전용 포토샵을 설치하여 `Locales/ko_KR` 폴더 자체가 존재하지 않는 경우
- CS6 등 구버전에서 다른 파일명(`tw10428.dat`)을 사용하는 경우

### 해결 방법
1. 내 컴퓨터의 파일 탐색기를 열어 실제 포토샵이 설치된 위치를 확인합니다.
   - 예: `C:\Program Files\Adobe\Adobe Photoshop 2023\Locales\ko_KR\Support Files`
2. 웹 페이지의 **[사용자 직접 지정]** 탭을 클릭한 뒤 실제 경로를 복사하여 붙여넣습니다.
3. 생성된 스크립트를 다운로드하여 실행합니다.

## 4. 언어를 바꿨는데도 포토샵이 여전히 이전 언어로 열리는 경우

### 원인
포토샵이 백그라운드 프로세스로 여전히 실행 중이거나 캐시가 남아있는 경우입니다.

### 해결 방법
1. 단축키 `Ctrl + Shift + Esc`를 눌러 **작업 관리자**를 엽니다.
2. 프로세스 목록에서 `Adobe Photoshop`이 켜져 있는지 확인하고 **[작업 끝내기]**를 누릅니다.
3. 배치 파일 또는 웹에서 언어 전환을 다시 실행한 뒤 포토샵을 실행합니다.

## 5. 브라우저 직접 연동 시 "지원하지 않는 브라우저" 메시지가 뜨는 경우

### 원인
Firefox, Safari 또는 구형 브라우저는 보안 정책상 웹 페이지가 사용자 로컬 폴더에 직접 접근하는 File System Access API를 지원하지 않습니다.

### 해결 방법
- **Chrome(크롬)** 또는 **Microsoft Edge(엣지)** 브라우저를 이용해 접속하시거나,
- 웹 페이지 하단의 **원클릭 배치 스크립트(.bat)** 또는 **.EXE 실행 파일 빌더**를 다운로드하여 사용하시면 모든 브라우저 및 환경에서 제한 없이 사용하실 수 있습니다.

## 6. Windows .EXE 단독 실행 파일 생성 시 SmartScreen 또는 백신 경고가 뜨는 경우

### 원인
새로 빌드된 로컬 실행 파일은 마이크로소프트 디지털 서명이 없는 개인 제작 파일이므로, Windows SmartScreen 또는 일부 안티바이러스 프로그램이 초기 1회 실행 시 보안 확인 창을 표시할 수 있습니다.

### 해결 방법
1. SmartScreen 화면이 나타나면 **[추가 정보]**를 클릭합니다.
2. 아래쪽에 나타나는 **[실행]** 버튼을 클릭하시면 정상 동작합니다.
3. 생성된 `Photoshop_Language_Toggle.exe` 파일은 Windows 순수 내장 컴파일러(`iexpress.exe`)를 통해 제작된 무해한 파일이며, 오직 포토샵 로케일 파일 이름만을 안전하게 토글합니다.

## 7. 데스크톱 앱(PWA) 설치 버튼이 동작하지 않거나 나타나지 않는 경우

### 원인 및 확인 사항
- 이미 컴퓨터에 앱이 데스크톱 프로그램으로 설치되어 있는 경우 브라우저 설치 버튼이 비활성화될 수 있습니다.
- 사크릿 모드(시크릿 창)에서는 브라우저 보안 규정에 따라 PWA 설치가 제한됩니다.

### 해결 방법
1. Chrome 또는 Edge 일반 창에서 접속합니다.
2. 브라우저 주소창 맨 오른쪽 끝의 컴퓨터 모니터 모양 `[설치]` 아이콘을 직접 클릭하셔도 즉시 설치됩니다.
3. 이미 설치된 경우 시작 메뉴의 "포토샵 언어 변경기"를 검색하여 실행할 수 있습니다.

## 8. VBScript 실행 시 백신(Windows Defender, V3, 알약 등)에서 오진하는 경우

### 원인
- `.vbs` 파일 형식은 과거 웜/바이러스 유포에 악용된 전력이 있어, 국내외 백신(AhnLab V3, 알약, 카스퍼스키, Defender 등)이 웹에서 다운로드된 VBS 스크립트에 대해 매우 엄격한 **휴리스틱(Heuristic) 탐지 룰**을 적용합니다.
- 특히 검은 콘솔창을 띄우지 않고 권한을 요청하는 동작 패턴(`runas`, `wscript.exe`)이 백신에 의해 악성코드 패턴으로 의심(False Positive)받기 쉽습니다.

### 해결 방법 및 권장 사항
1. **표준 스마트 토글 배치 파일(`.bat`) 사용 (강력 권장)**:
   - 본 앱의 `.bat` 파일은 순수 Windows 내장 CMD 명령어로만 작성되어 백신 오진율이 0%입니다.
   - 메모장으로 언제든지 내용을 직접 열어 안전성을 투명하게 검증할 수 있습니다.
2. **바탕화면 바로가기 생성기 사용**:
   - `create_desktop_shortcut.bat`를 실행하면 안전한 배치 파일 기반으로 바탕화면에 바로가기 아이콘을 깔끔하게 생성합니다.
