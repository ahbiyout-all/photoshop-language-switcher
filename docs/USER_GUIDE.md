# 사용자 가이드 (User Guide)

포토샵 언어 변경기를 사용하여 한글과 영어를 손쉽게 전환하는 전체 사용 절차 가이드입니다.

---

## 1. 사전 준비 작업
- **포토샵 완전 종료**: 포토샵이 실행 중인 상태에서는 언어 데이터 파일(`.dat`)이 포토샵 프로세스에 의해 잠금(Lock) 처리되어 파일 이름이 변경되지 않습니다. 반드시 포토샵을 완전히 종료해 주세요.

---

## 2. 독립형 데스크톱 GUI 앱 및 배포 패키지 (.ZIP) 활용 (가장 추천)
> 검은 콘솔창 없이 세련된 윈도우 그래픽 창에서 버튼 클릭으로 전환하며, 다른 사용자에게 배포할 수 있는 완성형 패키지를 제공합니다.

### A. 독립형 HTML GUI 애플리케이션 (.hta) 실행
1. 상단 **[GUI 앱 생성 & 원클릭 배포 스튜디오]**에서 **[.HTA GUI 앱 다운로드]**를 클릭합니다.
2. 다운로드된 `Photoshop_Language_Switcher_GUI.hta` 파일을 더블클릭합니다.
3. 별도 런타임/프로그램 설치 없이 Windows 자체 창 프로그램으로 즉시 실행됩니다.
4. 현재 포토샵 로케일 상태를 실시간 확인하고, **[자동 토글]**, **[영어 모드]**, **[한글 모드]** 버튼을 눌러 손쉽게 제어합니다.

### B. 종합 배포 패키지 (.ZIP) 내보내기
1. **[종합 배포 패키지 (.ZIP) 내보내기]** 버튼을 클릭합니다.
2. `Photoshop_Language_Switcher_v1.3.0_Distribution_Suite.zip` 파일이 즉시 다운로드됩니다.
3. 압축 파일 내에는:
   - `Photoshop_Language_Switcher_GUI.hta` (단독 GUI 앱)
   - `Photoshop_Switcher_WPF_GUI.ps1` (모던 WPF GUI 앱)
   - `scripts/` 폴더 내 백신 안전 배치 스크립트 5종
   - `README_배포안내.txt` (상세 배포 설명서)가 모두 포함되어 있어 다른 사용자에게 전달하기에 최적입니다.

## 3. 방법 A: 브라우저 직접 연동 (가장 빠름, 추천)
> Chrome 또는 Microsoft Edge 브라우저를 사용할 때 지원됩니다.

1. 웹 페이지 상단에서 본인의 **포토샵 버전** 또는 **사용자 지정 위치**를 선택합니다.
2. [브라우저 직접 폴더 연동] 섹션에서 **[내 컴퓨터 Support Files 폴더 선택]** 버튼을 클릭합니다.
3. 파일 탐색기 창이 열리면 해당 포토샵의 `Support Files` 폴더를 찾아 선택하고 '폴더 선택'을 누릅니다.
4. 브라우저에서 '파일 수정 권한 허용' 팝업이 뜨면 **[허용]**을 클릭합니다.
5. 현재 언어 상태가 표시되면:
   - **영어로 변경** 버튼 클릭 시 즉시 영어 모드로 전환
   - **한글로 변경** 버튼 클릭 시 즉시 한글 모드로 복구
   - **원클릭 토글** 버튼 클릭 시 현재 상태의 반대로 즉시 전환
6. 포토샵을 실행하면 변경된 언어로 열립니다.

---

## 4. 방법 B: Windows .EXE 단독 실행 파일 자동 생성 (최고 추천)
> 별도의 스크립트나 검은색 콘솔 창 없이 바탕화면에 독립적인 `.exe` 실행 파일을 영구 생성합니다.

1. 웹 페이지 상단에서 본인의 포토샵 버전을 선택합니다.
2. [원클릭 실행 파일 & 스크립트 생성기]에서 **[.EXE 실행 파일 빌더]**를 선택하고 **[build_photoshop_toggle_exe.bat 다운로드]**를 클릭합니다.
3. 다운로드한 파일을 더블클릭합니다 (Windows UAC 자동 승인 창에서 [예] 클릭).
4. Windows 내장 IExpress 컴파일러가 자동 구동되어, 수 초 내에 바탕화면에 **`Photoshop_Language_Toggle.exe`** 단독 실행 파일이 생성됩니다!
5. 이제 앞으로 언어를 바꾸고 싶을 때마다 바탕화면의 `.exe` 파일만 더블클릭하면 끝납니다.

---

## 5. 방법 C: VBScript 무음 GUI 런처 (.vbs) 실행
> 검은색 CMD 창이 번쩍거리는 게 싫고, 세련된 윈도우 안내 팝업을 원할 때 사용합니다.

1. [원클릭 실행 파일 & 스크립트 생성기]에서 **[VBScript 무음 GUI 런처]**를 선택하고 **[photoshop_toggle_gui.vbs 다운로드]**를 클릭합니다.
2. 다운로드된 `.vbs` 파일을 더블클릭합니다.
3. 콘솔 창 없이 백그라운드에서 조용히 언어가 전환되며, Windows 정품 대화상자(MsgBox)로 *"성공: [영어 모드]로 변경되었습니다!"* 알림이 뜹니다.

---

## 6. 방법 D: 바탕화면 바로가기 자동 생성 (.bat)
1. **[바탕화면 바로가기 생성]** 탭에서 **[create_desktop_shortcut.bat 다운로드]**를 클릭합니다.
2. 더블클릭하여 실행하면 바탕화면에 "포토샵 한영 전환" 바로가기 아이콘이 즉시 등록됩니다.

---

## 7. 방법 E: 원클릭 배치 파일 (.bat) 다운로드 실행
> 브라우저 권한 팝업 없이 윈도우 바탕화면 등에서 언제든 클릭 한 번으로 바꾸고 싶을 때 사용합니다.

1. 웹 페이지 상단에서 본인의 포토샵 버전 및 설치 드라이브를 선택합니다.
2. 만약 포토샵을 D 드라이브나 다른 폴더에 설치했다면 **[사용자 직접 지정]** 탭을 누르고 경로를 입력합니다.
3. [원클릭 실행 파일 & 스크립트 생성기] 섹션에서 **[스마트 자동 토글 (.bat)]** 탭 선택 후 **[photoshop_toggle_language.bat 다운로드]** 버튼을 클릭합니다.
   - *다운로드되는 파일은 자동으로 **Windows CRLF** 개행 및 **UTF-8 with BOM** 인코딩으로 저장되어 한글이 절대 깨지지 않습니다.*
4. 다운로드된 `.bat` 파일을 **일반 더블클릭**으로 실행합니다.
   - **자동 관리자 권한 승격(UAC)**: 스크립트 내부에 자동 권한 승격 로직이 포함되어 있어, "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?" 팝업이 자동으로 뜹니다. **[예]**를 누르면 끝입니다!
   - (필요 시 기존처럼 마우스 우클릭 후 **[관리자 권한으로 실행]**을 선택하셔도 무방합니다.)
5. 검은색 콘솔 창이 뜨며 현재 상태(한글/영어)를 자동으로 감지하여 반대 언어로 안전하게 변경됩니다.
6. 포토샵을 실행하여 언어가 정상 적용되었는지 확인합니다.

---

## 8. 단독 데스크톱 앱(Desktop App)으로 PC에 설치하기
본 애플리케이션은 Chrome, Edge 등 현대적인 데스크톱 브라우저에서 **독립 실행 데스크톱 앱(PWA)**으로 설치할 수 있습니다:
1. 화면 상단 타이틀바의 **[데스크톱 앱 설치]** 버튼 또는 브라우저 주소창 우측의 [설치] 아이콘을 클릭합니다.
2. 설치 팝업에서 **[설치]**를 누르면 컴퓨터 시작 메뉴 및 바탕화면에 독립 앱으로 등록됩니다.
3. 브라우저 탭, 주소창, 툴바 없이 일반 윈도우 프로그램처럼 전용 창에서 쾌적하게 실행되며, **인터넷 연결이 끊긴 오프라인 상태에서도 완벽하게 작동**합니다.
