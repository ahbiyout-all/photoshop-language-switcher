## 💡 요약: "개인정보 파일과 bat 스크립트를 같이 올려도 될까요?"

### 1. 자동 스크립트 (`.bat` 파일들) 👉 **"네, 반드시 같이 올리시는 것을 권장합니다!"**
- **대상 파일:** `build.bat`, `deploy_gh_pages.bat`, `github_setup.bat` 등
- **안전한 이유:**
  1. 본 프로젝트의 `.bat` 스크립트들에는 **어떠한 개인 비밀번호나 GitHub Personal Access Token(PAT)도 하드코딩(텍스트로 저장)되어 있지 않습니다.**
  2. 스크립트 실행 중 토큰이 필요한 경우 사용자에게 화면에서 임시 입력을 받거나, 윈도우의 보안 자격 증명 관리자(Windows Credential Manager)를 통해 브라우저 로그인 창으로 안전하게 처리합니다.
  3. 이 스크립트들은 다른 PC에서 프로젝트를 내려받거나 일반 사용자가 ZIP을 받았을 때 **마우스 더블 클릭만으로 빌드 및 배포를 수행할 수 있게 해주는 핵심 편의 기능**이므로 깃허브에 함께 올라가 있어야 완벽한 오픈소스 역할을 합니다.

## 🛡️ 프로젝트 내 자동 보안 안전망 (`.gitignore`)

프로젝트의 루트 디렉터리에 위치한 `.gitignore` 파일에 의해, 아래와 같은 민감 파일들은 **실수로 `git add .`를 하더라도 깃허브에 절대 올라가지 않도록 자동 차단**되어 있습니다:

```gitignore
# 환경 변수 및 시크릿 파일 (자동 차단)
.env
.env.local
.env.*.local
*.secret
*.token
*.pat
*.pem
*.key
*.pfx
*.p12
credentials.json
client_secret*.json

# 개인 작업 폴더 (자동 차단)
personal/
private/
```

따라서 개인적인 메모나 비공개 토큰을 임시로 보관하셔야 할 경우, 프로젝트 폴더 안에 `personal/` 또는 `private/` 폴더를 만들어 보관하시거나 파일 확장자를 `.token`, `.secret` 등으로 지정하시면 Git이 자동으로 무시하므로 안전합니다.

2. [x] `.env` 파일에 실제 API 키를 넣었다면 그 파일이 Git에 추가되지 않았는가?  
   👉 *(`.gitignore`에서 이미 차단하고 있으므로 안심하셔도 됩니다.)*
3. [x] `git status` 명령을 실행했을 때 이상한 개인 문서(`.txt`, `.docx` 등)가 Untracked 목록에 들어가 있지 않은가?
